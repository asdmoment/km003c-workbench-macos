## 主工作区：两种观察方式

同一图表区域切换“全程趋势 / 细节检查”，保留来源、全程导航、时间选区和共享游标位置。切换只改变观察方式，不改变采集、录制或积分。

全程趋势用来判断整体充电走势。密集数据采用按显示时间/像素范围聚合的原始min/max包络，避免简单每N点抽样遗漏已经采到的峰值；聚合包络表示该桶的幅值范围，不能表示桶内每个尖峰的精确时刻、顺序或宽度。趋势线可选叠加。

细节检查复用主绘图区，优先显示所选U、I或P通道。示例局部量程为8.95–9.05V；刻度保持真实工程单位，明确标注“局部放大”。提供自动局部、锁定量程、从零三种纵轴行为，默认依据所选区间的原始数据确定局部范围。最小跨度须考虑有效分辨率，避免把量化跳动无限放大。比较两个区间时使用同一量程。

细节模式默认原始点折线；点数足够稀疏时显示采样点。选择“原始＋趋势”才叠加平滑结果，算法及窗口时长在图旁可见。原始极值参与量程或显示带真实数值的越界标记，不能静默夹到边缘。

默认电流和功率可能走势近似；细节模式给一个通道主要空间，其他通道通过游标值和可选共享时间轴的小轨核对。双向及零点分析应显示带符号值，不以绝对值折叠方向。

## 区间如何区分

- 时间导航始终保留全程，选中区间以统一浅色框和准确起止时间对应到主图。
- 使用A/B两个游标确定选区，一行给出Δt、ΔU、ΔI、ΔP；时间取实际采样时间，近似数据明确标注。
- 选区摘要默认只列最小、平均、最大、峰峰值和点数；更多容量、能量和波动统计按需展开。峰峰值为所选原始样本最大减最小，包含异常点，不能直接当作高频纹波指标。
- 支持“与上一选区比较”，固定通道、纵轴、滤波口径，并展示均值差和峰峰值差；不为每一段自动涂上不同颜色。
- 暂停、断线、已捕获的协议变化和人工标记可作为事件竖线。没有协商依据时不自动命名为快充、恒流或恒压阶段。
- 数据空缺处断开折线；旧聚合区标“概览”。细看旧录制区间时按需读取已封口的数据段，异步加载并保留当前选区；原始文件不可用时继续说明近似性。

## 页面重心

```text
┌──────── 导航 · 唯一设备状态 · 连接 · 设置 ────────┐
├──────── 录制 · 计时 · SPS · 文件操作 ─────────────┤
│ 实时表计       │ 来源 · 全程趋势 / 细节检查        │
│ U              │ 通道 · 原始/趋势 · 纵轴范围       │
│ I              ├─────────────────────────────────┤
│ P              │                                 │
│                │         主要波形观察区          │
│ 会话累计       │                                 │
│                ├─────────────────────────────────┤
│ 协议/信号摘要  │ A/B与选区摘要 · 展开统计          │
│                ├──── 全程导航＋当前选区框 ────────┤
└──────── 实际采样信息 · 数据质量 · 错误 ────────────┘
```

常规左栏约232–240px，紧凑约216–224px；三张读数卡等高，实时数字32–36px。移除每张卡重复的统计盒，窗口统计统一跟随选区；会话累计和协议保留紧凑摘要。完整信号与协议信息进入对应分析页。

顶部图表标题、来源和观察模式合并为紧凑工具行。全程跟随只显示一份全部摘要，手动选区时改为选区摘要，需要比较时再展开全部。累计曲线仍可开启，进入细节模式时默认收为累计数值摘要，保留用户在趋势模式的可见性设置。

目标：1280×820的实际绘图区高度至少约350px，1024×700约260px；这是待真实窗口验证的设计目标。主图、摘要和导航使用统一的右边界，避免多个大小不同的外框。大窗口新增空间优先给波形，不把所有间距同比例放大。

未连接时把连接、导入和最近记录入口收在一张紧凑状态卡。已连接未录制时，可另行考虑不落盘的短时预览；需用户认可这种行为变化后再实现，默认不创建会话。留白承担清楚的操作引导，不填入无关装饰。

## 视觉原则

沿用现有灰阶容器、U蓝/I绿/P橙、能量粉和容量紫的语义。色彩只表示通道或明确事件，不表示任意时间片。标题/正文用系统字体，数据与游标用Menlo/SF Mono；辅助11px、正文13px、标题16px、计时20px、读数32–36px。

绘图区底板保持稳定的深色，主网格少量清晰、次网格较弱。日系壁纸继续覆盖应用背景，主图使用足够的不透明遮罩；取消图表标题重复的角色小图，避免纹理与毛刺混在一起。视觉识别沿用左侧通道色条，并让同一选区框贯穿主图和导航。

直接影响图表的显示方式、通道和量程放在图旁；设置页保留默认值、语言、皮肤、录制及设备配置。不要再把检查细节需要的控件藏到多层设置。

## 实施优先级与验收

1. 局部真实纵轴、原始显示优先、原始极值不静默裁切；对照已知尖峰和小幅台阶样本验证幅度与游标值。
2. 全程/细节复用工作区、选区摘要、量程锁定与A/B比较；检验两种窗口下主图获得有效面积。
3. 旧录制段的原始回读、概览身份及区间对照；用长录制验证超过环形缓存后仍可查原始点，加载过程中采样与按钮保持响应。

同一份原始数据在相同窗口、量程和滤波条件下与官方软件对照；核对值及峰值时间，不凭曲线粗糙程度判定准确性。真实KM003C采样、实际SPS和前端带宽尚未在本次审查中验证。

提高显示放大倍率只能揭示已采到的变化。50 SPS名义采样间隔20ms；采样间隔内没有捕获的瞬态无法通过UI恢复。设备前端带宽、内部滤波和采样率决定观察能力，不把采样峰峰变化标成示波器级高频纹波。
