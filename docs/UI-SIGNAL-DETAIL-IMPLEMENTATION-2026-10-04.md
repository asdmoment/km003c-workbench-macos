# KM003C 原始细节与界面重心：第一阶段实施

日期：2026-10-04。范围：测量显示与监控页布局；不改变 USB、PD、录制状态机、积分算法或 CSV/Parquet 23 列契约。

本轮依据 `UI-SIGNAL-DETAIL-CONCEPT-2026-10-04.md`，先交付局部真实量程、全程/细节工作区和仪表栏减重。该构思中的 A/B 比较、已封口原始段异步回读和带方向细节视图不属于本轮完成项。

## 已实现

### 原始波形优先

- 新配置默认原始曲线；旧配置中的降噪选择仍可读取。
- “叠加趋势”只增加五点中值趋势，不替换原始曲线。图表范围和选区统计仍以原始数据为依据。
- 显示抽稀保留桶内极值。聚合显示不代表桶内每个峰的精确时间、宽度或顺序。
- 锁定量程不把越界值夹到轴边缘；界面明确提示越界数据及实际范围。
- 绘图区使用不透明深色底板，日系壁纸仍保留在应用背景，不混入曲线和网格。

### 两种观察方式

- “全程趋势”：保留 U/I/P、可选累计轨和全程导航。
- “细节检查”：选择 U、|I| 或 |P|，使用真实工程刻度，提供局部、从零和锁定量程。
- 细节模式自动收起累计轨，回到全程时保留原有累计曲线选择；不改变录制、当前选区或已固定游标。
- 时间范围继续复用全程/最近窗口/手动查看逻辑；手动查看仍可回到最新，导航双击仍可恢复全程。
- 横轴使用稳定的 1/2/5 时间间隔，按约 110px 的标签空间选择刻度，小窗口下长时间文字不再相邻覆盖。
- 稀疏细节显示实际采样点。所选细节通道的游标精度随量程细分，不再把 9.000V 和 9.003V 都显示成 9.00V。
- 细节摘要显示最小、样本平均、最大、峰峰值及点数；平均直接计算来源样本，不平均抽稀后的顶点。

### 页面减重

- 仪表栏收窄，三张读数卡等高，保留等宽大读数与独立单位列，移除每张卡重复的统计盒。
- 累计、协议和信号线压缩为同宽摘要；统计集中在波形下方。
- 全程跟随只显示一行摘要；全部/窗口对照按需展开。
- 细节工具栏整合通道、纵轴量程、时间范围及游标固定操作，不再重复显示相同通道图例和标题。

## 数据边界

- 主图电流和功率沿用既有绝对值口径，按钮与摘要明确标为 |I| / |P|，并非带方向波形。
- 细节“样本平均”包含暂停期间仍显示的实时样本；录制累计量继续按既有规则排除暂停，不混淆两种统计。
- 最近完整缓存仍为 100000 点，旧实时历史仅有概览桶。本轮不会凭概览桶伪造原始细节。
- 进入旧区间时标明原始缓存起点；细节图留空并标识“无原始细节”，不把旧概览的近似游标冒充原始读数。
- 检查更早完整原始数据仍需保存后导入文件。按需读取已封口数据段的能力尚未实现。
- 局部放大只能显示已经采到的变化，显示精度不代表设备精度；峰峰值不是示波器级高频纹波测量。

## 窗口验收结论

- `1280×820`：细节模式主绘图区约 390px 高；`1024×700`：约 270px 高。测量指绘图区，不包括工具栏、游标栏、统计和时间导航；无额外告警时测得。全程模式启用累计轨后，主轨高度会相应减少，不声称所有模式都达到相同高度。
- 简中与 English、工业与日系皮肤实际窗口已检查；三张仪表卡等高，无卡片重叠，工具栏和导航未横向溢出，底栏可见。
- 模式和通道有明确选中边框。电压、电流、功率可独立细看，趋势叠加可关闭；原始峰值仍可见。
- 实际操作验证了录制中打开设置、切换语言与皮肤、暂停、量程选择和导航双击。时间及累计量继续变化；锁定量程越界时出现明确警示。
