# KM003C 工作台 · 原始波形与细节检查

发布日期：2026-10-04 · App `0.1.0 (5)` · 发布标签 `v0.1.0-20261004`

## 本次更新了什么

- 新增“全程趋势”和“细节检查”两种工作区。全程观察充电过程，细节页可单独查看电压 U、绝对值电流 |I| 或绝对值功率 |P|，使用真实工程单位刻度。
- 新增“局部量程／从零量程／锁定量程”。局部量程便于观察毫伏、微安等小变化；锁定量程后，越界值保留并给出提示。
- 新配置默认原始曲线。“叠加趋势”增加五点中值趋势，原始波形仍可见；旧配置中的趋势选择保持兼容。游标、统计和保存文件继续使用原始数据。
- 细节统计显示原始样本的最小、样本平均、最大、峰峰值和点数。稀疏数据标出实际采样点，游标精度随量程调整。
- 重新整理左侧仪表栏：三张读数卡等高、收窄，单位独立对齐；累计、协议和信号线压缩为摘要，统计集中在波形下方。
- 改进中英文、小窗口和长时间轴布局。采用稳定的 1/2/5 时间刻度，减少标签重叠；细节模式自动收起累计轨，返回全程时恢复选择。
- 包含此前 KM002C 兼容改动：识别 VID `5FC9` / PID `0061`；USB reset 后按原 PID 和序列号重新打开设备。未知 PID 不接入。

## 数据口径与使用提示

- CSV/Parquet 仍保持原有 23 列，既有文件和偏好可继续使用，无需迁移。
- 主图及细节电流、功率按绝对值显示，|I| / |P| 不代表方向；净能量等录制累计量沿用现有口径。
- 最近完整原始缓存为 100000 点。更早的实时历史只有概览桶，细节页明确标记“无原始细节”；需要完整历史细节时，请保存后导入录制文件。
- 细节的“样本平均”统计当前来源的原始样本，包含暂停时仍显示的实时数据；录制累计量按实际写入区间计算，暂停期间不累计。
- 局部放大和更多小数位只改善显示，不能提升设备采样精度；峰峰值不等同示波器高频纹波测量。
